# Carbine

A Rust engine with a thin Python scripting layer. See `fullspecv1.md` for the live API
contract and `mapAndaudioprocess.md` for the working log.

Quick starts:

```bash
python examples/maps.py
python examples/sound.py
python examples/video.py [clip.mp4]
python examples/chess.py
```
